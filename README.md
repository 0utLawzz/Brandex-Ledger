# Brandex.pk Consultants Ledger

Responsive web ledger for Brandex consultants.

## Features
- **73 consultant ledgers** fully imported from Excel (3,276 transactions)
- Same columns: Date, Folder No, Stage, TM No, Details, Due, Received, Balance
- Payment rows preserved and highlighted
- Responsive design for Desktop & Mobile
- Print Preview (A4 landscape) — **no pure black**; uses Dark Maroon / Navy / Cream palette
- Search & filter ledgers
- Dashboard with total balance overview

## Colors (no black shades)
- Deep Maroon `#4A1520` / Maroon `#6B1E2A`
- Navy Deep `#0D1B2A` / Navy `#1B2A41`
- Cream / Gold accents

## Run
Open `index.html` or deploy to any static host / Vercel.

Data is embedded in `data.js` (or load from `ledgers_data.json`).
