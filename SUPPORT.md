# Support

## Before asking for help

Please check:

- The latest `README.md`
- Existing GitHub Issues
- Recent commits/releases

## Bug reports

For a reproducible bug, open a GitHub issue and include:

- Browser and version
- Device/OS where relevant
- Exact steps to reproduce
- Expected behavior
- Actual behavior
- Console error, if available
- Screenshot when useful

Never post passwords, API keys, private client data, or confidential case information.

## Feature requests

Explain:

- The problem
- The proposed solution
- Why it is useful
- Any compatibility concerns
