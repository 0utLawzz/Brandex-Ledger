# Security Policy

## Supported versions

The latest version on the default branch is the primary supported version.

## Reporting a vulnerability

Please do **not** publish sensitive vulnerability details in a public GitHub issue.

Instead, report security concerns privately to the repository maintainer through GitHub's private security reporting mechanism, if enabled, or through the private contact method listed by the project owner.

Include:

- A clear description of the issue
- Steps to reproduce
- Affected files or functionality
- Potential impact
- A suggested fix, if known

Please allow reasonable time for investigation and remediation before public disclosure.
